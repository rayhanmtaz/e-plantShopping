# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shopping web application built with React and Redux Toolkit. Users can browse various categories of houseplants, view plant details and prices, add plants to their shopping cart, adjust item quantities, and see real-time cost calculations.

## Features
- Landing page with company overview and navigation to the product catalog.
- Categorized plant listing featuring Air Purifying, Aromatic Fragrant, and Insect Repellent plants.
- Interactive shopping cart powered by Redux Toolkit (`addItem`, `removeItem`, `updateQuantity`).
- Real-time total item counter in the navigation bar and dynamic subtotal/total cost calculation.
